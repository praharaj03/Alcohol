# Mojito Landing Page

**Version 1.0.0**

A responsive cocktail landing page built with React, Vite, Tailwind CSS, and GSAP. The page features a mojito-themed hero, cocktail menu, and scroll-triggered animations.

## Getting started

Install [Node.js](https://nodejs.org/) and npm, then run:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually [http://localhost:5173](http://localhost:5173)).

The development command identifies the project and version in the terminal:

```text
> mojito-landing-page@1.0.0 dev
```

## Available commands

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Build the production site in `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |

## Tech stack

- React
- Vite
- GSAP with ScrollTrigger and SplitText
- Tailwind CSS

## Project structure

- `src/components/` - page sections and navigation
- `constants/` - cocktail and page content
- `public/images/`, `public/videos/`, and `public/fonts/` - static site assets
